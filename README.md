# Go Video

Клиент VK Видео для BMW iDrive 7 (MGU ID7) на основе RideTube. Устанавливается через MGU Store с USB. Гостевой каталог, поиск и публичное видео доступны без входа. Версия 0.1.4 добавляет экспериментальный вход VK ID по QR и проверяет доступ к `video.get` перед сохранением аккаунта.

## Установка

Распакуйте архив тестовой сборки, скопируйте папку `mgu-repo` в корень флешки и откройте **Store → USB → Go Video**. Для проверки раннего старта выберите ролик, которого ещё нет в медиатеке.
