# Go Video

Клиент VK Видео для BMW iDrive 7 (MGU ID7) на основе RideTube. Устанавливается через MGU Store с USB. Гостевой каталог, поиск и публичное видео доступны без входа. Версия 0.1.4 добавляет экспериментальный вход VK ID по QR и проверяет доступ к `video.get` перед сохранением аккаунта.

## Установка

Распакуйте архив тестовой сборки, скопируйте папку `mgu-repo` в корень флешки и откройте **Store → USB → Go Video**. Для проверки раннего старта выберите ролик, которого ещё нет в медиатеке.

## Регистрация VK ID

1. Опубликуйте `docs` через **GitHub Settings → Pages → Deploy from a branch → main → /docs**. Убедитесь, что страница `https://<владелец>.github.io/go-video/oauth_callback.html` открывается по HTTPS. Можно разместить этот же файл на другом HTTPS-сайте под вашим управлением.
2. В [кабинете VK ID](https://id.vk.com/about/business/go) создайте приложение **Go Video** для платформы **Web**. Введите базовый домен опубликованной страницы и её полный URL в поле **Доверенный Redirect URL**. Скопируйте числовой **ID приложения**.
3. Установите Go Video 0.1.4. Из PowerShell передайте публичный ID и точный URL в MGU по уже настроенному SSH. Если ключ хоста хранится отдельно, укажите `-KnownHostsFile`.

```powershell
.\Configure-VK.ps1 -MguIp "<IPv4 MGU>" -Key "<путь к ключу>" -ClientId "<ID приложения>" -RedirectUri "https://<владелец>.github.io/go-video/oauth_callback.html"
```

4. Подключите телефон к точке доступа MGU, включите **Пульт с телефона** и дождитесь его QR. Вернитесь в меню Go Video, выберите **VK ID** и сканируйте QR входа. Завершите вход на сайте VK. Если браузер блокирует переход на MGU, повторите настройку с `-ManualReturn`, откройте пульт на телефоне и отправьте `GOVK ` с адресом возврата из браузера. Код действует до 10 минут.
5. Go Video запрашивает право `video`. После обмена кода служба проверяет `users.get` и `video.get` для этого пользователя. Ошибка прав или непустой результат проверки альбомов относятся к доступу VK API. Воспроизведение закрытого ролика проверяется отдельно. Текущий загрузчик по-прежнему открывает обычную ссылку VK Видео и не передаёт в него токен аккаунта.

Пароль вводится на сайте VK. Для настройки нужны только публичные `APP_ID` и Redirect URL. Токены остаются в состоянии MGU. Не публикуйте адрес, полученный после реального входа.

## Сборка

```powershell
python tools/build_go_video.py --sdk-dir oap-sdk --output ../Go_Video_0.1.4_test_USB
```

Понадобятся Python, Node.js и локальная копия BMW OAP SDK. После изменения интерфейса собирайте с SDK. Без SDK используется старый предсобранный интерфейс, который не показывает QR входа. Зависимости сверяются по `tools/dependency-lock.json`. Артефакты MGU Store, для которых в списке указан только файл, сначала положите в `vendor-artifacts` из оригинального каталога Store.
