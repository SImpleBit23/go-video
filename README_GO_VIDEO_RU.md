# Go Video 0.1.4

Клиент VK Видео для BMW iDrive 7 (MGU ID7) на основе RideTube. В этой тестовой версии доступны гостевой каталог, поиск, просмотр публичных роликов и сохранение в медиатеку. Каталог показывает последний сохранённый список и обновляет его в фоне.

## Установка и обновление через MGU Store

1. Откройте **Settings → Add source**.
2. Введите `SImpleBit23/go-video` и выберите **Releases**. Если Store просит URL каталога, укажите адрес ниже.
3. Откройте **Store → Go Video** и выберите **Install** или **Update**.

```text
https://github.com/SImpleBit23/go-video/releases/download/catalog/catalog.json
```

Тег [`catalog`](https://github.com/SImpleBit23/go-video/releases/tag/catalog) содержит список версий, зависимостей и контрольных сумм. Сами пакеты доступны в [релизе 0.1.4](https://github.com/SImpleBit23/go-video/releases/tag/v0.1.4). При обновлении повторно добавлять источник не нужно.

Если у MGU нет доступа к сети, можно использовать USB-пакет. Скопируйте папку `mgu-repo` в корень флешки и откройте **Store → USB → Go Video**.

## Проверка на MGU

- Откройте каталог и выполните поиск. Закройте приложение и откройте снова, чтобы проверить, появляется ли сохранённый список до завершения фонового обновления.
- Запустите из каталога публичный ролик, которого ещё нет в медиатеке. Проверьте первый кадр, звук, паузу и STOP. Совместимые MP4 могут начать играть до конца загрузки. Для остальных используется полная загрузка.
- Скачайте ролик в медиатеку и проверьте воспроизведение из «Скачанных».

На MGU подтверждён запуск видео из каталога в версии 0.1.2. Ранний старт и кеш проверены локально. Установку по сети и поведение 0.1.4 ещё нужно подтвердить на машине.

## Сборка

```powershell
python tools/build_go_video.py --sdk-dir oap-sdk --output ../Go_Video_0.1.4_test_USB
```

Нужны Python, Node.js и локальная копия BMW OAP SDK. После изменений интерфейса собирайте с SDK. Зависимости сверяются по `tools/dependency-lock.json`. Артефакты MGU Store, для которых в списке указано только имя файла, положите в `vendor-artifacts` из оригинального каталога Store.
